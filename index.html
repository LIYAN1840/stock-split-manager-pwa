每日收盘价

使用说明（点击展开）

支持两种录入方式：① 自动获取——点击“自动获取收盘价”（或每行的“获取”按钮），程序将从公开行情网站抓取价格并填入：收盘日期为今天时取实时行情；若今天是周末或节假日，会自动切换到最近交易日（腾讯为主、东方财富为备用；开盘前 9:30 前会明确标注为最近交易日收盘价，15:00 收盘后即为正式收盘价）；收盘日期为历史日期时取该日不复权真实收盘价（腾讯历史K线为主、东方财富历史为备用，另有多重兜底与自动重试）。填入后请核对再点“批量保存”。盘中保护：交易日 9:30—15:00 获取到的是实时行情，只用于当前持仓估值和当日盈亏预估，不写入历史收盘价；15:00 后重新获取才可保存为正式收盘价。② 手动填入——直接在“本次收盘价”列输入。
另有「补全历史收盘价」按钮：对全部成交过的股票一键抓取自建仓以来（最长约 400 个自然日）的每日不复权收盘价并直接入库（已录入的价格不会被覆盖），供「盈亏走势」长周期曲线使用。
“上一交易日价格”列显示严格早于所选收盘日期的最近一条已存价格（并标注其日期）。价格页的预估按交易资金流计算：期末持仓市值 ＋ 当日卖出成交额 − 期初持仓市值 − 当日买入成交额；首页和每日快照的“当日盈亏”再加上同日到账分红，与券商 App 口径一致。因此当日新买入部分以实际成交价为基准，原有持仓才以上一交易日价格为基准。同一股票同一日期仅保留一条有效价格；首次录入时会显示“暂无可比数据”。对当日新买入、本地尚无历史价格的股票，点“复制上一日价格”会联网抓取其上一交易日真实收盘价并自动入库（按代码+日期去重，不覆盖已有记录），该列随即显示真实价格与日期，不再显示“无更早记录”。

盈亏走势

口径与对比说明（点击展开）

口径说明（v1.8.6）：本面板支持三种日历周期：本周（周一至今天）、本月（当月1日至今天）、今年（当年1月1日至今天）；同时支持三种收益率口径，可在上方「口径」按钮切换，三种口径共用同一份逐日重建数据与上证指数曲线。
【账户总收益（默认）】即「基金单位净值法」。v1.8.2 已修复：系统自动生成的期初资金若晚于历史成交日期，将仅在走势计算中回溯至该归属人的最早成交日，避免历史买入被误判为现金透支、曲线重置。，以全部账户资金为分母：每日总资产 A = 持仓市值 + 现金余额（累计：资金投入 − 资金取出 + 其他资金增加 − 其他资金减少 + 卖出成交额 − 买入成交额 + 分红，按记录日期逐日累加）；当日外部净现金流 C = 当日（资金投入 − 资金取出 + 其他资金增加 − 其他资金减少）；当日收益 r =（当日 A − 前日 A − 当日 C）÷ 前日 A；区间收益率 = 逐日收益连乘 − 1，期初 = 0。特点：含仓位管理效果——低仓位/空仓躲过下跌时，超额收益会如实体现（持仓口径体现不出）；资金存取已剔除影响——存入/取出当日曲线无跳变；空仓时段（持仓市值为 0 且无资金存取）曲线自然平走、不断线；含分红（现金分红计入账户资产）。人员筛选：单人 = 该人自己的资金/持仓/分红独立计算；全部 = 两人现金流与持仓加总后再计算（并非两人收益率的平均）。前一日总资产 ≤ 0 时该日不贡献收益，重新有资产当日以 0 为新起点。
【券商口径·持仓】每日序列 = 当日浮动盈亏 ÷ 当日持仓成本，即券商 App 中看到的「持仓收益率」（自买入累计的绝对口径，复用逐日重建的持仓成本与浮动盈亏），再将序列期初首个有效值对齐为 0，曲线表示所选周期内该口径的百分点变化，与上证指数区间涨跌幅同基期对比；持仓成本为 0 的日期曲线断开。注意：与券商 App 口径一致，加减仓会因成本价重算而跳变，属该口径固有特征，不是程序错误。
【时间加权·持仓】即「区间持仓收益率」：按自然日逐日重建持仓后做时间加权链式累计，以周期初（或周期内首次建仓日）为 0 基点。当日收益 =（当日持仓市值 − 前日持仓市值 − 当日净买入额）÷ 前日持仓市值；区间持仓收益率 = 逐日收益连乘 − 1。该口径只统计持仓股票的市值变动：剔除闲置现金（资金投入多少不影响收益率）、不含已实现盈亏历史包袱、不含分红（与上证指数价格指数口径对等）；当日净买入额 = 当日买入成交额 − 当日卖出成交额（按实际成交价），中途加仓/减仓不会造成曲线跳变；前一日无持仓时曲线断开，重新建仓当日以 0 为新起点。无加减仓的时段券商口径与时间加权口径曲线斜率一致。
市值取每只股票“≤ 当日的最近一个收盘价”（尚无收盘价的持仓按成本计入）。悬停提示同时标注当前口径曲线值与其余两口径参考值；「持仓收益率（自建仓累计）」= 当日浮动盈亏 ÷ 当日持仓成本，为券商 App 同款绝对值；「累计总盈亏」=（当日市值 − 当日持仓成本）+ 截至当日累计已实现盈亏 + 截至当日累计分红，与首页/总览汇总面板一致。红涨绿跌遵循“系统设置”中的涨跌颜色习惯。
上证指数对比：图中虚线为上证指数同期涨跌幅，以所选周期首个数据日“≤当日”的最近一个交易日收盘价为 0 基点（与组合曲线同基期），非交易日沿用上一交易日收盘，指数数据缺失的日期曲线断开。区间对比摘要：组合值 = 当前所选口径序列期末值；上证指数区间涨跌幅 = 期末指数收盘 ÷ 基期指数收盘 − 1；超额收益 = 两者之差。指数数据缓存于本机浏览器（独立缓存键，不进入 JSON 备份），数据不可用时组合曲线照常显示。
非交易日处理：周末或节假日执行一键录入、自动获取或历史补全时，程序会先用上证指数日K识别最近交易日并自动回退，不再保存到周末日期。 历史补全的每个行情请求均有超时限制，单只股票超过约30秒会自动跳过并继续处理，不会停在某只股票上。 图表绘制会自动忽略异常收益率数据；“今年”周期仅显示代表性日期刻度，避免日期文字过密导致浏览器渲染异常。
历史收盘价补全：点击工具栏「补全历史收盘价」，程序会对全部成交过的股票抓取自建仓以来（最长约 400 个自然日）的每日不复权收盘价并合并入库；已有人工/自动录入的价格优先保留不被覆盖，补全结果随 JSON 备份一同保存（备份结构不变），长周期曲线精度随之提升。
数据新鲜度：当持仓股票的最新收盘价日期落后于上证指数最新交易日时，面板顶部会出现「收盘价滞后」提示条，此时组合曲线末端可能失真（假性跑输/跑赢），请先到「收盘价」页更新（或使用「补全历史收盘价」）后再对照。
